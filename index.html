PS4 WebKit Userland Exploit

A WebKit structured‑serialization (SSV) use‑after‑free userland exploit for the PlayStation 4 Internet Browser. On success it yields arbitrary read/write inside the browser process and runs a small kernel jailbreak stage.

📌 Overview

  • Target: PS4 firmware 5.00 – 13.52 (offset table included)
  • Vulnerability: WebKit structured‑serialization UAF
  • Primitive: Arbitrary read/write in the browser process
  • Chain: SSV UAF → addrof → fake cell → RW → sysent hijack → ucred patch → rootvnode
  • Entry point: jb.html loaded in the PS4 Internet Browser
  • Retries: up to 10 attempts per page load

🚀 Usage

  1. Cold boot the PS4 (fresh boot greatly improves reliability).
  2. Open the Internet Browser.
  3. Navigate to a hosted copy of jb.html — e.g. https://primehat06-wq.github.io/ps4-13.50/jb.html.
  4. Watch the on‑screen log (it prints into a <pre> element).
  5. If all 10 attempts fail, power‑cycle the console and load it once more.
Query parameters: ?n= drain count (64–1024), ?dbg=1 verbose kernel scan output, ?l=1 lite flag (reserved).
Example: jb.html?n=256&dbg=1

🧠 How it works

  1. Firmware detection — parses navigator.userAgent and selects the matching offsets from PS4_OFFSETS.
  2. SSV graph construction — K = 2 BigInt fillers, 0xfffe − K filler objects, a duplicated reference at index 2, and a control value at index 0xffff. Stored via history.replaceState.
  3. Addrof leak — a Proxy get trap on Leaker.prototype.__proto__ leaks a Symbol wrapper; Symbol.prototype.toString.call(...) copies live heap pointers into a string.
  4. Heap grooming — MessageChannel posts typed arrays to punch holes of known sizes, then a 0x80000 predecessor is filled with qword pairs pointing at a fake cell at host + 0x10.
  5. Trigger — history.state returns the deserialized graph; the duplicated reference yields two views over one ArrayBuffer. Rewriting one backing vector gives arbitrary read/write.
  6. Verify — checks SID / butterfly / vector fields and performs an 0xa5 read + 0x5a write/restore cycle on both views.
  7. Jailbreak — hijacks sysent[661] with a jmp rsi gadget, walks the proc structure for the "rror" marker to locate the ucred, patches uid/gid/ref/prison, swaps fd_rdir/fd_jdir to rootvnode, then restores sysent[661].
